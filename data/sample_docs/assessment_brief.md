# Assessment Brief Notes

The preliminary report contains four chapters: introduction, literature review, design and feature prototype. The feature prototype should show that one of the most important technical parts of the project is feasible.

The prototype does not need to be the final system. It should work as designed and include an evaluation of how well it performs. For this project, a suitable prototype would compare keyword search with semantic retrieval using known queries and expected passages.

The final report should explain improvements that would be made after testing. The evaluation should match the project area rather than using generic comments about whether the software looks good.
